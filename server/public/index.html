mldxf

Turn a STEP file into cut-ready DXF, tool plans, and clamp guides for your CNC.

Local only — this server binds 127.0.0.1 and serves no data beyond this machine.

About this app

About this app

The UI displays what the server API returns; the API mirrors the mldxf CLI. Library edits are validated before they are saved: an invalid save is refused and the file on disk is left unchanged.

Saving Preferences updates your settings right away.
